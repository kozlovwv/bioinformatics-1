## 2. Скрипт на Bash с реализованным алгоритмом

Файл:

```text
pipeline.sh
```

Назначение:

* запуск FastQC;
* картирование через BWA MEM;
* конвертация SAM → BAM;
* получение статистики через samtools flagstat;
* анализ процента картированных ридов.
* если OK -> samtools sort + freebayes
